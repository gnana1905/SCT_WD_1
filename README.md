# SkillCraft Studio — Modern Landing Page

A modern, high-performance, and responsive landing page engineered with clean semantic HTML5, modular CSS design tokens, and vanilla JavaScript.

## ✨ Features

- **Fixed Interactive Navigation**: Stays accessible at the top, dynamically changes background and shadow styling on scroll, with smooth active section highlighting.
- **Dark & Light Mode**: Seamless theme switching with persistent user preference storage via `localStorage`.
- **Responsive Architecture**: Fluid grid and flexbox layouts tailored for mobile, tablet, and desktop screens with custom hamburger drawer navigation.
- **Hero & Metrics**: Clear headline hierarchy, value proposition, and interactive metric counters.
- **Interactive Portfolio**: Filterable project showcase across categories (Websites, UI Design, Applications).
- **Accessible Contact Form**: Client-side form validation with inline error feedback and temporary success toast notification.
- **Back to Top**: Smooth floating action button that appears when scrolling down.
- **Zero Dependencies**: Pure HTML5, CSS3, and Vanilla JavaScript with no frameworks or bloated libraries.

## 📁 File Structure

```
├── index.html     # Semantic page structure & accessibility tags
├── style.css      # Design tokens, variables, typography, layouts & media queries
├── script.js      # Vanilla JS for navbar, theme toggle, filters & validation
└── README.md      # Documentation
```

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve locally using:

```bash
python -m http.server 3000
```
